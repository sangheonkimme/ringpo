# M2-2b — 브랜드 공유·PDF·신규 가입 귀속

검증일: 2026-10-22 UTC. 운영 배포·마이그레이션·실제 Meta 발송 없음. 분리 PostgreSQL 17 DB와 외부 쓰기 차단 fixture만 사용했다.

## 구현과 검증

- 256비트 읽기 토큰은 hash만 저장, 생성 응답에 한 번 반환. 저장한 리포트 버전만 익명 공유. 소유권/flag/공유·PDF entitlement, 만료/폐기/계정 삭제, 51개 공유의 cursor 페이지 탐색을 검증했다.
- 공유 웹/PDF의 strict DTO에 개인 필드가 들어가면 거부한다. 일반 클릭과 구분된 referral code로 30일 first-touch 신규 가입을 1회 집계한다. 실제 Better Auth magic-link 가입/재로그인 hook을 모의 메일로 검증했다. 만료/변조 cookie, 기존 사용자, HEAD/bot/prefetch는 귀속에서 제외한다.
- 타입 검사 16.70초, lint 15.83초, Next production build 51.81초, worker build 0.95초 통과. PDF.js 6에서 삭제된 테스트 옵션을 제거한 뒤 타입 검사를 통과했다.
- PDFKit+동봉 한글 글꼴을 포함한 **standalone 서버**에서 익명 HTML/PDF HTTP 200. 실제 PDF 36,070 bytes/1페이지를 PDF.js로 추출·렌더링해 한글과 매출 245,000원/CTR 50%가 동일 버전 웹과 일치하는지 확인했다. 새 실시간 매출은 280,000원이어도 공유한 버전 1은 유지됐다.
- 모바일 390×844 [브랜드 화면](m2-2b-brand.png), [소유자 발급 화면](m2-2b-owner.png), [PDF 렌더링](m2-2b-pdf.png). 모두 직접 시각 확인했다. JS 오류 0, 가로 넘침 없음. 리포트 응답의 no-store/no-referrer/noindex, 외부 글꼴 요청에 공유 URL referrer 미노출, 개인정보 필드 미노출, 가입 이동/HttpOnly cookie를 확인했다.
- **전체 기능 flag OFF 뒤에도** 설정에서 공유 관리 접근/폐기 가능. 두 링크를 폐기한 뒤 웹/PDF 모두 404. 직전에 생성한 PDF 캐시도 다운로드할 수 없었다. [폐기 화면](m2-2b-revoked.png). 이미 다운로드한 파일의 회수는 범위 밖이다.
- 독립 scoped 테스트: 공유/PDF/cookie 3개 파일 12개(9.10초), 가입 귀속 4개(5.32초) 통과. 이후 전체 회귀 **73개 파일/484개 테스트 통과(323.89초)**. opt-in 실제 10분 혼합 부하 1개는 별도 실행 항목으로 건너뛰었다. 전체에는 가상 시간/250계정 dispatch 부하와 기존 OFF 자동화·결제·로그인 회귀를 포함한다.

## 재현과 경계

`TEST_DATABASE_URL`은 반드시 폐기 가능한 별도 DB를 지정한다. 통합 테스트 준비 과정에서 public/drizzle schema가 초기화된다.
