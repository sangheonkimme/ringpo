# M2-2a — 성과 집계·수동 주문·리포트 버전

검증일: 2026-10-21. 운영 배포·마이그레이션·실제 Meta 발송 없음.

## 구현과 검증

- DM logical job과 성공이 확인된 링크 수신자를 집계한다. 공개 답글/재시도 횟수/단순 링크 생성은 발송 수에 더하지 않는다. 확인되지 않은 링크 클릭은 CTR에서 분리한다.
- 상품별 고유 클릭을 전체 고유 클릭으로 더하지 않는다. KST 시간대와 같은 공개 후 경과 시간의 직전 공구를 비교한다. 주문 미입력은 `—`로 표시하고 미입력 항목은 증감 비교에서 제외한다.
- 수동 누적 주문·KRW 매출은 revision/수정자/시각으로 보관한다. 저장된 snapshot은 이후 클릭·수치 수정으로 바뀌지 않는다. 정산 후 수정은 새 확정 버전이며 이전 공유 대상 버전을 덮어쓰지 않는다.
- 상태 전환과 보고서 요청은 같은 DB tx. worker의 DB-only 작업에서 생성+완료를 원자적으로 처리한다. flag OFF 계정은 큐에서 제외해 다른 계정의 생성을 막지 않는다.
- 단위·통합·마이그레이션·기존 상태 서비스 4개 파일/21개 테스트 통과(17.62초). strict DTO의 개인 필드 거부, 소유권/flag, 동일 기간 비교, 중복 요청/worker, unknown 정산 확인, as_of 이후 클릭/주문, cascade 삭제, empty up/down/up과 이력 존재 시 down 거부를 확인했다.
- 타입/lint, Next 프로덕션 빌드(19.41초), worker 빌드 통과.
- 인증된 390×844 모바일 프로덕션 빌드에서 주문·매출 수정과 새 버전 저장 확인. [실시간 화면](m2-2a-live.png), [새 저장본](m2-2a-snapshot.png). CTR 50%(확인된 클릭 2명/링크 발송 4명), 전체 고유 클릭 3명 중 미확인 1명 별도 표시. 이전 저장본 245,000원은 유지하고 실시간/새 버전은 280,000원. HTTP 200, JS 오류 0, 가로 넘침 없음. 외부 요청 차단 fixture다.

전체 회귀 검사는 실행 중이며 결과가 확정되면 추가한다. 최초 fixture 시험은 필수 mediaId 누락으로 실패했고 fixture를 수정한 뒤 위 시험을 다시 통과했다. 공유·PDF·가입 귀속은 다음 PR 범위다. 실제 250계정에 대한 새 report 조회 비용은 후속 M2 혼합 부하에서 검증한다.
