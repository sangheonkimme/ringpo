## 링포 디자인 시스템(v2)에 가져온 것

`tools/figma-ringpo-ds` 기준이다.

**브랜드와 색**
- **로고·심볼·앱 아이콘:** 말풍선 두 개를 이은 심볼과 ringpo 워드마크.
  - 기존 v1은 자리만 비워 두었다.
- **색 이름과 값:** 원본 22색과 의미 색 37개를 그대로 가져왔다.
  - Lime은 `#CCF76B`로 바로잡았다. 기존 v1은 보드 이미지에서 읽은 `#C0F86B`였다.
  - 보조 글자색이 `#6B7280`이 되어 흰 바탕 대비가 4.83:1이 됐다. 기존 `#8A909C`는 3.2:1이었다.
- **포커스 색과 상태 색:** 포커스는 파랑 `#4168DA`이다. 상태는 성공, 주의, 위험(빨강), 중립 4가지다.
- **버튼 색:** 누른 상태·마우스를 올린 상태 색과 사이드바 색 토큰.

**글자와 모양**
- **타입 스케일:** 32 / 24 / 20 / 16 / 14 / 12, 숫자는 36.
- **그림자 2종:** Small, Medium.

**컴포넌트**
- **버튼:** 크기 2가지(44 / 36), 상태 6가지(Hover · Pressed · Focus · Disabled · Loading 포함).
- **새로 들인 컴포넌트:** Icon Button, Checkbox, Nav Item, Metric Card, Message Bubble, 사용량 표시(Usage Meter).

**화면 구성**
- 데스크톱은 어두운 사이드바에 선택 메뉴를 라임으로 칠한다.
- 대시보드는 숫자 카드 4개와 DM 미리보기로 구성한다.
- 자동 DM 설정은 01·02·03 단계 카드와 오른쪽 미리보기로 구성한다.

## 가져오지 않은 것과 이유

- **메뉴 `메시지함 · 프로필 링크 · 고객 · 분석`:** 링포에 없는 기능이다. 실제 메뉴인 홈 · 자동화 · 결제 · 설정으로 바꿨다.
- **"새로운 대화" 지표:** 받은 메시지함 기능이 없다. 대신 링포가 이미 집계하는 대기 중인 댓글을 쓴다.
- **자체 아이콘 20개:** 앱은 `lucide-react`를 쓴다. 그래서 Lucide 모양은 유지하고 선 두께 1.75px만 따랐다.
- **입력창 글자 14px:** iOS Safari는 16px 미만 입력창을 누르면 화면을 확대한다. 입력 글자만 16px로 올렸다.
- **데스크톱 전용 구성:** 링포 사용자는 대부분 모바일로 들어온다. 모바일 아래 탭(Tab Bar Item)을 더했다. 사이드바는 넓은 화면에서만 쓴다.
- **한 페이지 한 프레임 구조:** 기존 구조를 유지했다. Foundations / Components / Examples 3페이지이고, 다시 실행해도 결과가 같다.
- **디자이너 플러그인 자체:** v1.0.1에서 아이콘이 네모로 보이는 오류가 있었다. v1.0.2는 Figma에서 실행 검증을 하지 않았다.

## 남은 확인 사항

- **라임 토글 대비:** 켜짐 트랙과 흰 바탕의 대비가 1.23:1이다. 시안과 보드 모두 같다. 손잡이 위치와 색 차이로 상태를 구분한다.
- **사용량 예시 값:** Usage Meter의 "120 / 300"은 무료 플랜 한도를 가정한 예시 값이다.
