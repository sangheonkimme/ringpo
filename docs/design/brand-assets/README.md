# 링포 브랜드 이미지 묶음

원본은 디자인 시스템 로고(`svg/`, 외주 시안의 말풍선 심볼)예요. 색은 Ink `#142338`, Lime `#CCF76B`이고, 글꼴은 Pretendard예요.
앱 아이콘은 모두 정사각형(모서리 없음)으로 만들었어요. 모서리는 각 플랫폼이 알아서 둥글게 깎아요.

| 파일 | 크기 | 어디에 쓰나 |
|---|---|---|
| `meta-app-icon-1024.png` | 1024×1024 | Meta 개발자 → 앱 설정 → 기본 설정 → 앱 아이콘 |
| `kakao-app-icon-128.png` | 128×128 (5KB) | 카카오 디벨로퍼스 → 앱 → 일반 → 앱 기본 정보 → 앱 아이콘 (250KB 미만, 128 이하 권장). 비즈 앱 전환 전에 필요해요 |
| `profile-1080.png` / `profile-640.png` | 1080 / 640 | 링포 공식 인스타·카카오톡 채널 프로필 사진. 원형으로 잘려도 심볼이 안 잘리게 여백을 뒀어요 |
| `og-image-1200x630.png` | 1200×630 | 카톡·인스타 등에 링크를 공유할 때 뜨는 미리보기. 사이트에 이미 적용됨(`src/app/opengraph-image.png`) |
| `favicon.ico`, `svg/favicon.svg`, `apple-touch-icon-180.png` | 16~48 / 벡터 / 180 | 브라우저 탭 아이콘, 아이폰 홈 화면. 사이트에 이미 적용됨 |
| `app-icon-512.png`, `app-icon-256.png`, `app-icon-192.png` | | 그 밖에 앱 아이콘을 요구하는 곳(포트원 상점 로고, 구글 OAuth 동의 화면 등) |
| `app-icon-lime-1024.png` | 1024×1024 | 라임 바탕 버전(보조) |
| `logo-ink-1032w.png` | 1032×280, 투명 | 밝은 바탕용 로고(문서·메일·제안서) |
| `logo-white-1032w.png`, `logo-lime-1032w.png` | 1032×280, 투명 | 어두운 바탕용 로고 |
| `svg/*.svg` | 벡터 | 원본. 크기를 바꿔야 할 때 이걸 써요 |

다시 만들기: 이 폴더의 `generate.py`는 만들 때 쓴 스크립트예요(Chrome, Pillow 필요). 경로는 만든 환경 기준이라 그대로는 돌아가지 않아요.
